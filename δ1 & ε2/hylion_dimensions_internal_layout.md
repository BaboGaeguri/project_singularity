### 1층 — 배터리 (z: 0 ~ 65mm)

> **설계 의도**: 무게 중심을 최하단에 배치하여 보행 안정성 확보

```
y=0(앞)                                    y=180(뒤)
   ┌──────────────────────────────────────────────┐
x=0│  ┌──────────────────────────────────────┐   │x=250
   │  │    배터리 A (12V 8000mAh, 190×60mm)  │   │
   │  └──────────────────────────────────────┘   │
   ├──────────────────────────────────────── ─ ─ ┤ y=60
   │           ┌──────────────────┐              │
   │           │  배터리 B (서보)  │              │
   │           │  (100×50, 미확정) │              │
   │           └──────────────────┘              │ y=110
   │                                             │
   └─────────────────────────────────────────────┘

※ BHL 배터리 (22.2V 6S, 4000mAh, 599g) → 몸통 아님, BHL 골반/허리 자체 탑재
※ SO-ARM 배터리 → SO-ARM 키트에 포함
```

| 부품 | 전압 | 용량 | 치수 (가로×깊이×높이) | 무게 | 위치 | 담당 |
|------|------|------|-------------------|------|------|------|
| 배터리 A (메인) | 12V | 8000mAh (업그레이드 권장) | 190×60×30mm | ~500g ⚠️ | 앞쪽 (y: 0~60) | 컴퓨팅/IO |
| 배터리 B (서보) | 미확정 | 미확정 | 100×50×20mm | ~250g ⚠️ | 뒤쪽 (y: 62~112) | XL430 서보 등 |
| BHL 배터리 | 22.2V (6S) | 4000mAh | 135×42×49mm | **599g** ✅ | **골반 (확정)** | 다리 모터 |
| SO-ARM 배터리 | 자체 | 자체 | — | 키트 포함 | SO-ARM 키트 포함 | 팔 |

- 배터리 A/B 앞뒤 합계: 60 + 50 = **110mm < 180mm** ✅
- BHL 배터리는 몸통 1층이 아닌 **BHL 자체 위치(골반/허리)**에 탑재

### 2층 — 제어·전원 (z: 67 ~ 132mm)

> **설계 의도**: 평면 배치 부품 + 측벽 수직 고정 혼합

```
y=0(앞)                                    y=180(뒤)
   ┌──────────────────────────────────────────────┐
x=0│ ┌──┐ ┌─────────┐ ┌──────┐                  │

   │ │U │ └─────────┘ └──────┘                  │
   │ │2 │ ┌──────┐ ┌──────┐ ┌──────┐ ┌───────┐ │
   │ │D │ │ BMS1 │ │ BMS2 │ │ BMS3 │ │  PDB  │ │ y=100~140
   │ │2 │ └──────┘ └──────┘ └──────┘ │80×60  │ │
   │ │  │                             └───────┘ │
```

## 4. URDF 학습용 무게 요약

> 내부 부품 위치는 몸통 안에서 바뀌어도 재학습 불필요  
> 단, **몸통 ↔ 다리 간 부품 이동은 무게 중심 변화 → 재학습 필요**

| 파트 | 무게 | URDF 링크 |
|------|------|----------|
| 머리+목 | ~270g | head / neck |
| 컴퓨팅 (Jetson, BeeLink 등) | ~536g | torso |
| 제어·전원 보드 | ~463g | torso |
| 배터리 A+B (몸통) | ~750g | torso |
| SO-ARM 팔 ×2 | ~1,000g | torso |
| 구조재·배선·외피 | ~900g | torso |
| **몸통+상체 합계** | **~3,919g ≈ 4kg** | torso mass |
| BHL 배터리 | 599g | **pelvis (골반 확정)** |
| BHL 다리+프레임 | ~16,000g | legs |
| **전체 합계** | **~20.5kg** | |

## 5. 설계 결정 사항 (대화 중 논쟁 및 결론)

| 항목 | 결론 | 이유 |
|------|------|------|

| 몸통 높이 | 270mm (원래 250mm에서 +20mm) | 내부 부품 수직 합계 초과 |

## 7. CadQuery 시각화 스크립트

위 내부 배치를 3D STEP 파일로 출력하는 스크립트:  
`δ1 & ε2/hylion_internal_layout.py`

실행 방법:
```bash
# venv 재생성 (최초 1회)
Remove-Item -Recurse -Force .venv_design
py -3.11 -m venv .venv_design
.venv_design\Scripts\pip.exe install cadquery

# 실행
.venv_design\Scripts\python.exe "δ1 & ε2/hylion_internal_layout.py"
```

출력 파일: `δ1 & ε2/step_files/hylion_internal_layout.step`  
→ Onshape에서 Import하여 3D로 확인 가능
