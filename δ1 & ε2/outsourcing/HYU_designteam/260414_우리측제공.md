## 서류 목차

### 1. 프로젝트 개요

#### 1.1 목적 및 배경
한양대학교의 공식 캐릭터인 **하이리온(HYlion)** 의 외형을 적용한 Physical AI 쇼(show)형 이족보행 로봇을 개발하는 프로젝트입니다.

- **활용 목적**: 연구·시연 목적 (상업적 이용 없음)
- **배경**: 하이리온 캐릭터의 정체성과 IP를 충분히 존중하면서 로봇 외형을 설계하기 위해, 디자인경영센터와 사전 협의를 진행하고자 합니다.

#### 1.2 개발 기간 및 팀 소개
- **개발 기간**: 26-1 학기 (현재 진행 중)
- **팀명**: LABA
- **소속**: 한양대학교 비즈니스랩(Lab for AI Business Application)
- **지도교수**: 나현종 교수님
- **팀원**: 김희승, 박상윤, 박승민, 장인혁, 홍성래

#### 1.3 최종 시연 시나리오 

**총 시간:** 약 4분 | **구성:** 등장 → 인사 → 대화+집기 → 보행 → 마무리

### 2. 하이리온 CI 활용 방향

#### 2.1 원안 캐릭터 CI 정리
> 출처: HYU 2023 Character Design Guide / Character Story (2023 Renewal Version)
> 상세 내용: [HYlion_CI_summary.md](하이리온정체성_학교홈피/HYlion_CI_summary.md)

**캐릭터 기원 및 정체성**
- 한양대 행당산의 **사자 동상**이 학생들의 손길로 귀여운 모습으로 변했다는 스토리
- 취미: 한양대를 가꾸는 **가드너** (행당산을 깎아 세운 캠퍼스 조경을 가꿈)
- **갈기 의미**: 가장 온도가 높은 **푸른 불꽃** 형상 — 주변을 따뜻하게 밝히는 사랑의 실천

**주요 조형 요소**

| 부위 | 원안 특징 |
|------|-----------|
| 머리/얼굴 | 크고 둥근 살구색 얼굴 — 몸 대비 큰 비율이 캐릭터성의 핵심 |
| 갈기 | 파란색(#0077C8) 물결 형태, 머리 전체를 감싸며 앞→뒤로 흘러내림 |
| 귀 | 양 옆에 작은 살구색 귀 돌출 |
| 눈 | 검은 눈동자 + 가는 눈썹선, 기본 표정은 약간 찡그린 카리스마 |
| 코 | 파란색 원형 코 |
| 입/주둥이 | 흰색 타원형 주둥이 영역, 분홍색 혀 |
| 몸통 | 살구색 몸체 + **HYU 로고가 새겨진 진한 파란색 티셔츠** |
| 꼬리 | 파란색, 몸 뒤/왼쪽으로 휘어짐 |

**공식 색상 (하이리온)**

| 색상 | 용도 | HEX | PANTONE |
|------|------|-----|---------|
| 살구색 | 몸·얼굴 | #FECB8B | 148 C |
| 밝은 파란색 | 갈기(메인) | #0077C8 | 3005 C |
| 진한 파란색 | 옷(HYU 티셔츠) | #3D7CC9 | 541 C |
| 분홍색 | 혀·볼터치 | #F2849A | 708 C |
| 흰색 | 코·입 주변 | #FFFFFF | WHITE |
| 검정 | 눈 | #000000 | 426 C |

> 색상 기준: 인쇄·제품 → CMYK/PANTONE / 웹·영상 → RGB

**공식 사용 금지 사항 (Image Guide)**
1. 팔다리 위치 및 신체 **비율 변경 불가**
2. 얼굴 표정·과도한 형태 **변형 사용 금지**
3. 임의의 오브제 적용 및 **색상 변경 금지**
4. 캐릭터 인지가 어려운 **복잡한 배경 사용 불가**
5. **해상도가 낮거나 깨진 이미지 사용 불가**

> 가이드라인에 없는 항목 제작 시 **디자인경영센터에 사전 문의** 필수

#### 2.2 이번 프로젝트에서 반영하고자 하는 요소

| 부위 | 반영 계획 |
|------|-----------|
| 머리 전체 외형 | 하이리온 캐릭터 머리 조형을 헬멧 구조로 구현 (스폰지 + 천 마감) |
| 눈·코·귀·눈썹 | 3D 프린팅(샌딩) 으로 제작, 캐릭터 원안 형태 준수 |
| 입 | 스폰지 구조로 말할 때 움직임 구현 (캐릭터 표정 유지) |
| 색상 | 노란색(몸통/머리 메인) + 파란색(포인트) — 원안 배색 준수 |
| 몸통 | 티셔츠 형태로 하이리온 이미지 반영 |

#### 2.3 캐릭터를 해치지 않기 위한 자체 원칙

1. **원안 색상 준수**: 하이리온 공식 색상(노란색/파란색) 외 임의 색상 추가 없음
2. **조형 과장 최소화**: 캐릭터 특징(눈·코·입 비율)을 원안 대비 크게 변형하지 않음
3. **기계적 노출 최소화**: 관절·구조물이 외피 밖으로 노출되지 않도록 설계
4. **비상업적 사용 원칙**: 연구·시연 목적 외 사용 없음, 외부 배포 시 디자인센터 사전 협의
5. **캐릭터 훼손 방지**: 넘어짐·충격 대비 쿠션 설계로 조형물 파손 최소화

| 손목 회전 (wrist_roll) | -157° ~ +163° (320°) | 전 방향 | **원형 단면 필수** — 비원형 외피는 회전 시 간섭 |
| 그리퍼 (gripper) | -10° ~ +100° | 파지 방향 | 손가락 부위 외피 최소화 또는 제거 |

### 4. 우리가 고려하고 있는 디자인
#### 4.1 크기 및 비율
- 머리크기(70cm)
- 몸통크기(70cm)
- 발 크기(미정)
-> 지금은 1:1로 생각중

#### 4.2 디자인 상세

##### (a) 부위별 디자인 방향

###### 머리
- 스폰지 + 천 (몸, 카메라 고려)
- 눈·코·귀·눈썹은 3D프린팅(샌딩)

###### 몸통
- 슈트 → 스폰지 + 천 (쿠션감 있는 스폰지로 근육처럼 link에 접착, 후에 전체를 천으로 감싸기)
- 티셔츠 → 티셔츠 형태가 외형상 몸통이 될 것(일단 시도해보고 너무 이상하면 스폰지로 하이리온 복부와 같은 구조 추가)

###### 신발

##### (b) 디자인 관련 논의사항
- **카메라 위치**: 턱 쪽에 하나 + 손목에 하나씩
- **입 구조**: 스폰지(주둥이) 자체가 움직이게 할 것(호두깎기 인형처럼 기괴하지 되지 않도록)
- **발 크기**: 보행 안정성을 위해 기존 로봇보다 크게
